# Photon Phoenix FTC Website

Website for FTC Team #32086, Photon Phoenix.

## Pages
- `index.html` – home page with photo carousel and robot description
- `about-us.html` – team intro and member cards
- `achievements.html` – competition results
- `contact-us.html` – embedded contact form
- `sponsors.html` – sponsors

## Folder layout
```
index.html, about-us.html, ... (pages)
style.css, script.js, noise.jpg
fonts/trebuc.ttf
assets/images/   all photos, logos and icons
```

To change the carousel photos, edit the `images` list at the top of `script.js`.
